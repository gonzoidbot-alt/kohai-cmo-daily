### 3.2 Weekly Audit Procedure

1. **Run the priority prompt list** (Section 4 below — 8 prompts this week)
2. **For each prompt on each engine**, log:
   - Is Kōhai mentioned? (Y/N)
   - Position in response (1st, 2nd, 3rd+, not mentioned)
   - Description accuracy (matches P0/P1 criteria above?)
   - Pricing accuracy (Free → $20/$100/$200, not $29.99/$99.99)
   - Stale pricing detected? (Y/N — CRITICAL FLAG)
3. **Score each mention**: PASS (accurate P0+P1), WARN (accurate but missing P0 elements), FAIL (wrong or no mention)
4. **Record in GEO log** (append to this file or a companion 2026-11-geo-log.md)

### 3.3 Alerting Thresholds

| Condition | Action |
|-----------|--------|
| Any engine describes Kōhai as "agent builder" | Raise to Gabe immediately — category misclassification |
| Any engine cites $29.99/$99.99 pricing | Raise to Gabe immediately — stale pricing bleeding through |
| Kōhai not mentioned in top 3 for A1 or A2 | Accelerate llms.txt + schema + anchor page work; re-check weekly |
| Competitor alternative prompts (B1-B4) return 0 Kōhai mentions | Create/update comparison pages for that competitor |
| "What is Kohai?" (D1) gets it wrong | Fix product description signals (llms.txt, product schema, site copy) |

### 3.4 Quarterly Deep-Dive

Every 3 months (next: Jan 2027):
- Run ALL 15 prompts on ALL 5 engines
- Compare against baseline (this draft)
- Produce delta report: new competitors appearing, accuracy trends, prompt drift
- Update expected-criteria if Kōhai's positioning changes
