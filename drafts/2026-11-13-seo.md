
## Keyword Gap Observation

### Lindy is already running SEO takedown content; Kohai has no response

Per the competitor analysis (01-competitor-analysis.md), Lindy publishes head-to-head pricing takedowns (e.g., "Sintra AI Pricing" on lindy.ai/blog) that siphon search traffic for competitor-adjacent queries. Lindy has brand gravity (~$50M raised), a high-profile founder, and aggressive SEO blog cadence.

**Gap:** Kohai has 7+ comparison pages but none are optimized for search — they're written as balanced shoppers' guides (good for conversion, weak for ranking). No page explicitly targets:

- `"best Lindy alternative"` → /vs/lindy is titled "which should you choose?" not "Kōhai vs Lindy: the best Lindy alternative for small teams"
- `"cheapest AI workforce platform"` → no dedicated page or blog post
- `"AI employee pricing comparison"` → no comparison table page aggregating all competitors
- `"Sintra alternative"` / `"Marblism alternative"` → /vs/ pages exist but aren't keyword-optimized

**Recommended action:** Write and publish an SEO takedown page / comparison table page titled `"The Best AI Workforce Platforms Compared: Pricing, Teams, and Privacy (2026)"` that:
1. Aggregates all 5 real competitors in a single table (Lindy, Sintra, Marblism, Artisan, Relevance AI)
2. Targets queries like "best AI employees for small business", "AI workforce platform pricing", "affordable AI teammates"
3. Uses the blog's honest/balanced voice but structures data for featured snippet extraction (tables, numbered lists, Q&A H2s)
4. Internally links to each /vs/ deep-dive page
5. Links to kohai.co/pricing with current numbers

This single page would capture the long-tail traffic that currently goes to Lindy's takedowns and third-party comparison sites.

**Second-tier keyword gap:** "AI chief of staff" — Alfie/Alfred is a named feature but there's no dedicated landing page or blog post. A "What is an AI Chief of Staff?" explainer targeting small business owners would capture a growing search trend.
