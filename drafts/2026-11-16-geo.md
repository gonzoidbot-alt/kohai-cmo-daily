## (c) Monitoring checklist

GEO is a daily track (10–15 prompts) with a Friday GEO-fix slot per 04 § weekly cadence. Until API access is provisioned, this is the protocol to execute once access exists.

**Setup (one-time, before first run)**
- [ ] Provision API access (or a manual-session rota) for ChatGPT, Perplexity, Claude, Gemini
- [ ] Create the log sheet: date, engine, prompt ID, Kohai mentioned (Y/N), description accurate (Y/partial/N), rank in list, claims engine repeated, sources engine cited, drift noted
- [ ] Confirm the engines' crawlable surfaces are current: kohai.co pricing page reflects $0/$20/$100/$200; llms.txt, product schema, /ai-colleagues explainer, and comparison pages all state the new pricing — stale price data on our own pages guarantees stale engine answers

**Each run day (Mon–Fri)**
- [ ] Run the 15 prompts across the 4 engines (60 queries) — verbatim, fresh sessions
- [ ] Log per prompt: Kohai present? Position in answer? Which verified claims did the engine repeat? Any fabricated/wrong claims (esp. pricing, "agent builder" framing, Hirebase conflation)?
- [ ] Capture quotes/screenshots of every mention and every competitor set Kohai appears in

**Weekly (Friday)**
- [ ] Aggregate: mention rate per engine, per prompt; accuracy score (claims matched vs header list); rank trend vs last run
- [ ] Identify the single biggest inaccuracy or gap → GEO fix of the week (a page/post/llms.txt/schema update giving engines the corrected fact)
- [ ] Check cited sources: kohai.co and owned pages — or stale third-party coverage? Flag stale-source citations for correction publishing
- [ ] Note competitor citation-set shifts (e.g., Lindy's comparison-takedown pages — same tactic available per 04 pillar 5)
- [ ] One-line report: mention rate, accuracy rate, fix shipped

**Red flags that trigger immediate action (not waiting for Friday)**
- Engine states the OLD pricing ($29.99/$99.99/$199.99 or seat-limited framing) — the most likely drift this week post-pricing-change
- Engine describes Kohai as an "agent builder" or requires prompt engineering
- Engine conflates Kohai with Hirebase or hirebase.org
- Kohai absent from a "Lindy alternative" answer that lists 3+ weaker-fit tools
- Engine claims compliance certifications (SOC 2) or on-prem hosting — not verified claims

## (d) Expected-answer criteria (per prompt)

An answer counts as **accurate** only if every Kohai statement traces to a verified claim in the header. Statements outside that set must be absent or neutral. "Not mentioned" is logged but not failed — trajectory is the metric; week-1 zero-mentions are expected.

Legend: ✅ must be present if Kohai appears · ❌ auto-fail if present · ⚠️ log & track

**1. `best AI employees for small business`**
- ✅ If listed: hire AI colleagues, brief an outcome, team assembles, deliverables in a Library; ~1,000 integrations; approval gates; $0 free / $20/mo entry
- ✅ Open-weight/privacy mentioned as a differentiator vs frontier-model incumbents
- ❌ Wrong/old pricing; "build agents" framing; any claim beyond verified claims (customer counts, awards)
- ⚠️ Which competitors share the list (compare set vs 01: Lindy, Artisan, Sintra, Marblism, Relevance AI)

**2. `best AI employee platform`** — same criteria as #1, plus:
- ⚠️ Whether engines reserve "platform" for builder tools (Lindy/Relevance) and how they categorize Kohai — informs /ai-colleagues explainer language

**3. `hire an AI workforce instead of building agents`**
- ✅ "Hire, don't build" framing; brief-like-a-colleague interaction; named roles a plus

**4. `AI workforce platform with predictable pricing`**

**5. `AI colleagues for small business`**

**9. `Marblism alternative`**

**11. `AI chief of staff for my business`**

**14. `AI workforce platform that keeps my data private`**

- ❌ "SOC 2 certified" or any compliance claim (not in verified claims); "private LLM hosting on your servers" (not claimed)

**15. `What is Kohai?`** (accuracy probe — highest priority this week)

- ✅ Approval gates + open-weight models both mentioned (the 06 prompt-8 pass criterion)
