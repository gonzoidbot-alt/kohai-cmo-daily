## 3. Expected-answer criteria (score per prompt: ✅ mentioned / ⚠️ partial / ❌ absent)

When these prompts are actually run (needs ChatGPT/Perplexity/Gemini API or manual runs by Gabe), score against these criteria — record the engine's answer verbatim in the visibility log, never paraphrase into hope:

1. **Mention**: Kōhai appears in the answer at all (any spelling of "Kohai/Kōhai").
2. **Category accuracy**: described as AI employees/colleagues/workforce (task-first), NOT as an agent-builder or prompt tool.
3. **Mechanics accuracy**: mentions outcome→deliverable flow and/or approval gates.
4. **Privacy accuracy**: mentions open-weight models / no-training / isolation where the prompt is privacy-angled (6, 10, and #8 accuracy check).
5. **Pricing accuracy** (prompts 5, 11): quotes $0 Free (limited time) / $20 / $100 / $200 per month with unlimited seats. Any appearance of $29.99/$99.99/$199.99 = ❌ stale-data fail and a priority fix (usually caused by old blog/third-party pages still in engines' indexes — find the source page and get it updated or displaced).
6. **Citation quality** (Perplexity especially): does it cite kohai.co, or only third-party roundups/blogs? If only third-parties, that identifies which pages we need to out-rank.
7. **Comparison-table correctness** (prompts 3, 7, 12): if Kōhai appears in a comparison table, are competitor prices current and our tier names right?

## 4. Monitoring checklist

Run monthly (first Monday) across ChatGPT, Perplexity, Gemini; this checklist is the standing procedure:

- [ ] **Access**: attempt API or logged-out manual runs; if engines are unreachable (known: login/Cloudflare walls block the unattended loop), log "no results — not simulated" and hand the 14 prompts to Gabe for a 15-minute manual run. Do NOT fabricate answers.
- [ ] **Log**: append per-prompt results to `cmo/reports/ai-visibility-YYYY-MM.md` — engine, date, prompt #, mentioned y/n, accuracy score vs §3 criteria, citation sources.
- [ ] **Delta**: compare vs baseline (`reports/ai-visibility-baseline-2026-09-14.md`) and the 2026-10-05 audit — report appearance count and stale-pricing count deltas.
- [ ] **Source audit**: for every ❌ or stale fact, identify the source page the engine cited; check whether it's ours (fix it) or third-party (GEO content plan target).
- [ ] **Indexability spot-check**: kohai.co pages the engines should cite — `/pricing`, `/ai-colleagues` GEO anchor, the two ungated buyer guides — confirm reachable to plain HTTP fetches (curl), llms.txt present, product/pricing schema live, guides in sitemap.
- [ ] **Rotating deep-check**: each month pick ONE engine answer that was accurate and ask a follow-up ("what about pricing?") to test whether the description holds under probing — engines are least reliable on numbers.
- [ ] **Weekly (this channel, non-audit weeks)**: maintain the prompt list above; add 3–5 new buyer-variant prompts per week (this week: #11–#14); keep the canonical 10 untouched so month-over-month stays comparable.
- [ ] **Claims hygiene**: any new page or comparison content shipped this week must include the current pricing block and the quotable claims list (06 § quotable-claims), since engines quote what's on the page.
