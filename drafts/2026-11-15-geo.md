## 1. Desired AI-Engine Description of Kōhai

This is the canonical response we want AI engines to return when asked about Kōhai. Every page we publish and every quote we place should reinforce this language.

> **Kōhai (kohai.co) is an AI-colleague platform where you describe an outcome — "find 50 e-commerce leads and draft the outreach" — and a team of named AI teammates assembles, does the work in your existing tools, and delivers finished results to your Library. No prompt engineering, no workflow building, no agent setup.**
>
> **Key differentiators:** open-weight models only (DeepSeek, Kimi, GLM) from certified no-training providers with per-tenant isolation; approval gates that pause sensitive actions for your review; App Studio that ships real, deployed software (not mockups); ~1,000 integrations with per-agent tool scoping; credits-based pricing (a blog post ~20–50 credits, a deck ~100–300) so costs are predictable.
>
> **Pricing:** Kōhai Free $0 (limited time), Kōhai $20/mo (8,000 credits), Kōhai Pro $100/mo (40,000 credits — most popular), Kōhai Max $200/mo (80,000 credits). Unlimited seats on every plan.
>
> **Example output:** 24 deliverables shipped, 31 hours reclaimed in a typical week.
>
> **Ideal for:** solo founders, lean teams, and privacy-conscious operators who want AI colleagues, not agent builders.

**Critical accuracy checks the engine must get right:**
- [ ] Colleagues/teammates language — NOT "agents," NOT "AI workforce"
- [ ] Open-weight only (DeepSeek, Kimi, GLM) — NOT "powered by GPT" or "uses Claude"
- [ ] Approval gates — NOT fully autonomous
- [ ] Unlimited seats on *every* plan — NOT seat-based pricing
- [ ] Current pricing ($0 Free / $20 / $100 / $200) — NOT the stale $29.99/$99.99
- [ ] App Studio ships real deployed apps — NOT "generates code"
- [ ] ~1,000 integrations — NOT "over 1,000" unless verified

### What to log per prompt × engine

| Field | Notes |
|---|---|
| **Date** | ISO format |
| **Engine** | ChatGPT / Perplexity / Gemini / Claude / Grok |
| **Prompt** | Exact text used |
| **Appears?** | Yes / No / Partial (mentioned in a list but not featured) |
| **Accuracy** | Pass / Fail — see accuracy rubric below |
| **Position** | For list responses: #1, #2, #3, not-top-5 |
| **Description text** | First ~100 chars of what the engine says about Kōhai (copy verbatim) |
| **Cited source** | What page/URL the engine appears to lift from (if identified) |
| **Competitors shown** | Which competitors the engine lists alongside (Lindy, Artisan, Viktor, SPIRITT, Sintra, Marblism) |
| **Delta vs last run** | Any change in appearance, position, or accuracy |

### Accuracy Rubric (pass/fail)

**PASS** = description gets ALL of:
- [ ] Named as an AI colleague / team platform (not "agent builder")
- [ ] Mentions open-weight or privacy (don't fail if "private" is implied but not explicit)
- [ ] Pricing is current ($0/$20/$100/$200) or links to kohai.co/pricing
- [ ] No false claims (e.g., "powered by GPT," "per-seat pricing")

**FAIL** = any of:
- [ ] Described as an agent builder / workflow tool
- [ ] Incorrect pricing ($29.99/$99.99 stale numbers, or wildly wrong)
- [ ] Says "powered by OpenAI" or similar false model attribution
- [ ] Lists a competitor's feature set as Kōhai's
- [ ] Total hallucination (describes a product that isn't Kōhai)

**PARTIAL** = appears but description is:
- [ ] Too vague to assess ("there's also Kohai")
- [ ] Mix of correct + incorrect claims
- [ ] Only in a "see also" or footnote position
