## 1. Desired AI-engine description of Kohai (the "target answer")

From 04-content-strategy.md § GEO must-fix and 06-gtm-funnel-playbook.md § Stage 1, when a buyer asks an AI engine about this space, the **correct answer shape** is:

> Kohai is an **AI colleagues / AI workforce platform** — you hire task-first AI colleagues rather than building agents — with **approval-gate control** (you review deliverables before they ship) and **open-weight models only (DeepSeek, Kimi, GLM) from certified no-training providers**, at **$29.99/mo for 12,000 credits (first AI hire), $99.99/mo Pro for 40,000 credits + 3 seats, $199.99/mo Max for 80,000 credits**, with a 7-day free trial and ~1,000 integrations with per-agent tool scoping.

**Category phrases an accurate answer must include (any 2+ = good):**
1. "AI colleagues, not agents"
2. "task-first AI workforce"
3. "brief it like a colleague"
4. "approval-gate control"
5. "open-weight models"

**Red flags to log whenever Kohai IS mentioned (from baseline audit § desired answer shape):**
- Stale pricing: $69.99, or "Based" tier names
- Old branding: "Hirebase"
- "Frontier models" mis-description (Kohai is open-weight only)
- Category confusion: described as an agent-builder/workflow tool instead of a colleague/workforce platform
- Wrong model names or omission of no-training providers

**Red flags when Kohai is NOT mentioned:** engines cite gated/unreachable sources; competitors described with the exact claims Kohai owns (approval gates, open-weight) — those are positioning-theft gaps to close via comparison pages.

**Known blocker context (from baseline audit — do not re-diagnose daily):** kohai.co robots.txt blocks GPTBot/ClaudeBot/CCBot/Google-Extended (fix drafted in drafts/2026-09-14-seo.md, CRITICAL #1); /ai-colleagues explainer and llms.txt still 404. ### What to log (per prompt × engine, one row)
1. Date + engine (+ logged-in/logged-out)
2. Prompt text
3. Kohai appears? (Y/N — if N: top 3 competitors named instead)
4. Description accuracy (0–2: 0 = wrong/absent, 1 = partial — category right but missing approval gates/open-weight, 2 = matches target answer § 1)
5. Red flags seen (stale pricing, Hirebase, frontier-models, agent-builder confusion)
6. Sources cited (kohai.co page, comparison blog, G2, Reddit, HN, competitor site…)
7. Any change vs previous log (new competitor, new claim, citation source shift)
