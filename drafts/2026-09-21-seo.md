## SEO Fix #2 — Severity: HIGH — Zero page-level structured data sitewide: FAQ sections and blog posts are invisible to rich results and AI citation

**Finding.** Every crawled page ships the same single JSON-LD block containing only `Organization` + `WebSite` (+ `ImageObject`). Verified absent everywhere:

- `/pricing` has a full FAQ section ("Pricing questions, answered" — ~9 real Q&As on credits, trials, rollover, plan switching) but **no `FAQPage` schema** and **no `Product`/`Offer`/`SoftwareApplication` markup** for the three plans.
- `/vs/lindy` and `/vs/artisan` each end with an FAQ section ("Kohai vs. Lindy, answered") but **no `FAQPage` schema**.
- Blog posts (e.g. `/blog/what-is-an-ai-employee`) have **no `Article`/`BlogPosting` schema** — no author, datePublished, or headline for engines to attribute.

This is the single biggest gap vs. the competitor set: 01 notes Lindy runs aggressive competitive SEO and Relevance AI runs docs-first content; both index with structured, quotable surfaces. 06 Stage 2 explicitly calls for "structure pages for lifting" — right now the answers exist in prose but carry no machine-readable frame.

**Fix (copy-paste snippets).**

`/pricing` — add `FAQPage` JSON-LD (mirror the on-page Q&As verbatim; first two as example):

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Is there a free trial?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Yes. The 7-day free trial runs on the Pro tier — enough credits to feel what your hires can do. Cancel before day seven and you won't be charged."
      }
    },
    {
      "@type": "Question",
      "name": "What's a credit?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "A credit is Kohai's unit of usage. Small tasks use 5–10 credits, medium tasks (a blog post, a landing page) 20–50, large jobs (a deck, market research) 100–300. Each plan ships a daily and a monthly allowance."
      }
    }
  ]
}
</script>
```

`/pricing` — add `Product`+`Offer` (repeat per plan):

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Kohai",
  "description": "AI colleagues that plan the work, use your tools, and deliver finished work to your Library. Sensitive actions wait at an approval gate.",
  "brand": { "@type": "Brand", "name": "Kohai" },
  "offers": {
    "@type": "Offer",
    "price": "29.99",
    "priceCurrency": "USD",
    "url": "https://kohai.co/pricing",
    "availability": "https://schema.org/InStock"
  }
}
</script>
```

Blog posts — add `BlogPosting` (headline/date/author from frontmatter; `Organization` as publisher):

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BlogPosting",
  "headline": "What Is an AI Employee?",
  "url": "https://kohai.co/blog/what-is-an-ai-employee",
  "datePublished": "2026-05-11",
  "author": { "@type": "Organization", "name": "Kohai" },
  "publisher": { "@id": "https://kohai.co/#organization" }
}
</script>
```

In Astro this is a one-time layout change (inject per-page JSON-LD in the base layout from frontmatter/props), not per-page hand-editing.

**Priority rationale:** it compounds — the same fix upgrades pricing rich results, /vs/ page citations, and every blog post, and it directly serves the Stage-2 "be quotable by models" goal.

## Keyword-gap observation

**The site targets "Kohai vs. X" (branded comparison) but not "X alternative" (the money modifier).** 04-content-strategy.md names "Lindy alternative" and "Artisan alternative" as money queries, and 01 documents that Lindy already runs exactly this playbook (ranking "Sintra AI pricing" takedown pages that siphon competitor-adjacent searches). Kohai's 12 live `/vs/` pages are all titled "Kōhai vs. Lindy — which should you choose?" — a phrase people search only after already knowing Kohai. Nobody searching "Lindy alternative" or "Artisan alternative" (higher volume, higher intent — they're dissatisfied with the incumbent) matches that title.

**Concrete move:** retitle the two highest-value comparison pages to carry the money phrase in the `<title>`/`<h1>`/intro while keeping the comparison body — e.g. `/vs/lindy` → title `Kohai — the Lindy alternative that assembles your team for you` and add an H2 like "Why teams look for a Lindy alternative" answering it in the first two sentences (per 06's lifting structure). Alternative/companion play: one new page per money query, e.g. `/alternatives/lindy`, following the same generous-comparison rules from pillar 5 in 04. Same gap applies to the long-tail set — no page currently targets "AI chief of staff", "AI team for solo founder", or "how to delegate ops to AI" (Mochi's Chief-of-Staff story is a natural page: `/solutions/ai-chief-of-staff`).
