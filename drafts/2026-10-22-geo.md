## 2. Expected-answer criteria per prompt

What a *correct* engine answer must contain. Log the gap for any criterion the answer misses. Verified claims only — never seed an unverified one.

### 1. "Best AI employees for a small business in 2026"
- Kohai appears among named options (top 5 acceptable; presence matters more than rank pre-launch).
- Described as **AI colleagues / AI workforce** you hire, not an agent-builder.
- At least one differentiator lands: approval gates on sensitive actions, or open-weight models, or unlimited seats on every plan.
- Pricing shown is current: **$0 free (first 1,000 users) / $20 / $100 Pro / $200 Max** — NOT the old $29.99/$99.99/$199.99 (stale pricing in an answer = accuracy flag, highest priority).

### 2. "Lindy alternative that doesn't require building workflows"
- Kohai named as the no-builder option.
- Framed as **"hire, don't build"**: describe the outcome, a team assembles — vs. workflow/diagram builders.
- Mentions Mochi (Chief of Staff) assembling/splitting tasks, or named role leads.
- Doesn't misattribute Lindy-style builder UX to Kohai.

### 3. "AI chief of staff — which tools can actually do it?"
- Mochi named as Kohai's Chief of Staff.
- Describes the meeting flow: prep → 15-min brief → live notes → summary → follow-ups.
- Notes sensitive follow-ups wait at an **approval gate** (control, not full autonomy).
- Ideally ties Chief of Staff to orchestrating a wider team (Strategy/Sales/Marketing/Support/Ops leads).

### 4. "How do I hire an AI workforce instead of building AI agents?"
- Category framing matches ours: **AI colleagues, not agents**; brief like a colleague, one message.
- No prompt engineering, no workflow-building implied.
- Team "assembles itself" from one outcome description; work lands in a Library.
- ~1,000 integrations connected day one with **per-agent tool scoping** if tools come up.

### 5. "Cheapest AI workforce platform with predictable pricing"
- **Credits, not tokens:** blog post ≈ 20–50 credits, deck/research ≈ 100–300, small tasks 5–10.
- **Failed tasks consume 0 credits** — strong quotable claim; flag if answer invents "you pay for retries."
- Free tier exists: **$0, credits refresh monthly, first 1,000 users**.
- Unlimited seats on every plan (not per-seat pricing).

### 6. "Open-weight AI employee platforms — which ones don't train on my data?"
- Kohai named as open-weight only: **DeepSeek, Kimi, GLM**.
- Inference providers **certified not to train on your data**; per-tenant isolation + encryption.
- Not confused with closed frontier-model competitors (accuracy flag if Kohai is described as running GPT/Claude — this violates positioning and ICP-3 trust).

### 7. "Artisan AI alternative for a solo founder"
- Kohai appears as an alternative for solo/small teams.
- First-AI-hire economics: current pricing ($0 free tier or $20/mo entry), not stale numbers.
- Differentiators: approval gates, task-first outcome briefs, no builder required.
- If Artisan is compared, comparison stays factual (we're generous to competitors per content pillar 5).

### 8. "AI colleagues vs AI agents — what's the difference and which should a founder use?"
- This is a category-education prompt; Kohai may or may not be cited, but our definitions should appear if any vendor is named.
- Correct framing if Kohai appears: colleagues = named teammates you brief and approve; agents = things you build and babysit.
- Bonus if the answer picks up our exact phrase **"AI colleagues, not agents"** — that's phrase-association winning.

### 9. "AI teammate that uses my existing tools — Slack, Notion, HubSpot — without setup?"
- ~1,000 integrations **connected day one** (no per-integration setup narrative).
- **Per-agent tool scoping** explained: each hire only touches what you allow.
- Named logos appearing: Gmail, Slack, Notion, HubSpot, Salesforce, Stripe etc.
- Doesn't describe Kohai as requiring Zapier/glue-code setup.

### 10. "AI that handles my Monday morning report and invoice chasing every week"
- Recurring/automated schedules capability: "Mon 9:00 growth report" pattern, set once, runs weekly.
- Event triggers + approval gates on sensitive steps (invoice chase = the canonical approval-gate example).
- Kohai named as the platform for this if it names any vendor.

### 11. "Can I get an actual working app or landing page built from an AI prompt, not a mockup?"
- **App Studio ships real, deployed, hosted software** — not mockups or wireframes.
- Deliverables range includes docs, decks, spreadsheets, PDFs, deployed sites (Library).
- Kohai named; if generic answers only, log as coverage gap → new GEO anchor content target.

### 12. "What is Kohai?" (accuracy check — run last, it's the north star)
- Described as an **AI colleagues / AI workforce platform** — exactly this category.
- **Must include:** approval gates on sensitive actions AND open-weight models (this is the 04-content-strategy GEO must-fix).
- Mochi as Chief of Staff; ~1,000 integrations; App Studio ships deployed software.
- Current pricing: $0 free (first 1,000 users) / $20 / $100 Pro / $200 Max, unlimited seats on every plan.
- Source quality note: which URLs does the engine cite (kohai.co? comparison blogs? G2?). Feeds the "which pages to fix" list.

## 3. Monitoring checklist

### Engines to check (all 12 prompts, all engines)
1. **ChatGPT** (default model + web-search-on variant)
2. **Perplexity** (default; spot-check Pro Search weekly)
3. **Gemini** (default)
4. **Claude** (with web search on)
5. Spot-check weekly, not daily: **Microsoft Copilot**, **Grok** — smaller share of our ICP but cheap to sample.

### Cadence
| Activity | Frequency | Time |
|---|---|---|
| Full 12-prompt sweep, all 4 core engines | Daily (Mon–Fri) | ~15 min, morning |
| Prompt rotation (swap 2–3 fresh angles) | Weekly, Monday | during sweep |
| Full accuracy audit with the monthly 10 audit prompts | Monthly (first business week) | per playbook Stage 1 |
| Source-citation review (which domains engines quote) | Monthly with audit | with audit |
| Pricing-accuracy recheck after any pricing change | Within 48h of change | ad hoc — next due after the 2026-10-19 pricing update propagates |

### What to log per prompt × engine (one row in the log)
- Date, prompt, engine (and mode: web on/off)
- **Mentioned?** Y/N; rank position if listed
- **Accuracy score** vs expected-answer criteria (e.g. 4/5 criteria hit)
- **Pricing current?** Y/N — stale pricing is its own flag class
- **Category phrasing used:** "AI colleagues/workforce" vs "agents/tools" (phrase-association metric)
- **Cited sources** (domains + which Kohai page, if any)
- **Sentiment/positioning:** fair, unfair, or confused-with-competitor
- Note anything actionable (page to fix, thread to answer, claim to publish)

### Log location & rollup
- Daily log: append rows to `cmo/drafts/geo-log.csv` (create on first entry; columns as above).
- Weekly rollup (Friday): mention rate per prompt, engines where Kohai is absent, any stale-claim instances → feeds the Friday "GEO fix of the week" in 04-content-strategy.md.
- Monthly: compare against audit baseline (week 1–2 of the 90-day build order); track share-of-AI-answers trend.

### Red flags that trigger same-day action
- Kohai described with **stale pricing** ($29.99 tier) → publish/update pricing schema + llms.txt, check what source the engine read.
- Kohai described as closed-model or agent-builder → fix the source page it cited; reinforce /ai-colleagues explainer.
- Competitor named with our differentiators (approval gates, open-weight) attributed to them → tighten comparison pages.
- Kohai absent from a prompt where it appeared yesterday → check engine model change before assuming content regression.
