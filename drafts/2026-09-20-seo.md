## Fix 2 (Severity: HIGH — 3rd flag, now precisely scoped to one template edit + one page edit) — sitewide JSON-LD is still a single generic block; zero Article/FAQPage/Product schema, zero sitemap lastmod

**Evidence (crawled 2026-09-20):**
- Sampled pages today: home, /pricing, /vs/lindy, /vs/artisan, /vs/sintra, /vs/marblism, /vs/relevance-ai, /blog, and 4 posts — **every one carries exactly one JSON-LD block with types `Organization`, `ImageObject`, `WebSite`**. Zero `Article`/`BlogPosting`, zero `datePublished` in any JSON-LD, zero FAQPage despite 8 live FAQ questions on /pricing ("What's a credit?", "Do unused credits roll over?", "Is there a free trial?", "What if I run out of credits?", "What if a task fails or I cancel it halfway?", "What's the difference between the plans?", "What's the difference between daily and monthly credits?", "Can I switch plans mid-cycle?"), zero Product/Offer on the plan cards ($29.99/12k · $99.99/40k/3 seats · $199.99/80k/unlimited, all verified rendering on-page today).
- sitemap-0.xml: 52 URLs, **zero `<lastmod>` entries** (unchanged).
- Why it matters per 01/06: Lindy's SEO engine is head-to-head pricing content, and AI engines quote structured, dated, attributable pages at higher rates. Kohai's blog is strategically right ("The Predictable AI Bill", "What an AI Job Actually Costs") — but to a citation engine every post is an undated, authorless marketing page. The content wrapper is the gap, not the content.

**Copy-paste fix — one PR on the blog layout template** (visible dates already exist per post; lift them into schema — `2026-05-11` shown as the example):
```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "What Is an AI Employee?",
  "datePublished": "2026-05-11",
  "dateModified": "2026-05-11",
  "author": { "@type": "Organization", "name": "Kōhai", "url": "https://kohai.co" },
  "publisher": { "@type": "Organization", "name": "Kōhai", "url": "https://kohai.co" },
  "mainEntityOfPage": "https://kohai.co/blog/what-is-an-ai-employee"
}
</script>
```
Templated off the existing `<time datetime>` value, so one PR fixes all 17 posts; add `<lastmod>` to sitemap-0.xml entries in the same PR.

**And one block on /pricing** (matches the live accordion copy; full 3-question version in 09-19 § Fix 2 — top 2 shown here):
