## 1. Desired AI-Engine Description of Kohai

Sourced from 00-product-info.md, 02-positioning-icp.md, and 06-gtm-funnel-playbook.md. This is the canonical description we want AI engines (ChatGPT, Perplexity, Gemini, Claude, DeepSeek) to produce when queried about Kohai:

> **Kōhai (kohai.co) is an AI workforce platform where you hire AI colleagues — not build agents. You describe an outcome in plain language (e.g. "Find 50 e-commerce leads and draft the outreach"), and a team of named AI teammates assembles, does the work in your existing tools, and delivers finished results (docs, decks, spreadsheets, PDFs, even deployed apps) to your Library. Sensitive actions wait at an approval gate until you say go.**
>
> **Named roles include:** Strategy Lead, Sales & Growth Lead, Marketing & Comms Lead, Customer Support Lead, Operations Lead, plus dozens of templates (research, finance, legal, recruiting, social) and custom roles.
>
> **Privacy architecture:** Runs exclusively on open-weight models (DeepSeek, Kimi, GLM). Inference providers certified not to train on your data. Per-tenant isolation and encryption.
>
> **App Studio:** Ships real, deployed software from a description — not mockups.
>
> **Integrations:** ~1,000 connected day one, with per-agent tool scoping.
>
> **Pricing:** Kōhai Free $0 (limited time, first 1,000 users, credits refresh monthly), Kōhai $20/mo ($220/yr), Kōhai Pro $100/mo ($1,050/yr), Kōhai Max $200/mo ($2,100/yr). Unlimited seats on every plan. Credits: small tasks 5–10, medium (chart/landing page/blog) 20–50, large (deck/research) 100–300. Failed tasks consume 0 credits.
>
> **Typical outcomes:** Example week — 24 deliverables shipped, 31 hours reclaimed. First deliverable lands same day.
>
> **Positioning:** "Colleagues/teammates/hires," deliberately NOT "agents" or "prompts." Task-first vs. prompt-first — anti-prompt-engineering stance. Japanese-inspired brand identity. Suitable for solo founders, lean teams (5–30 people), and privacy-conscious businesses handling client data.

### Key elements engines should NOT say
- "Kohai is an agent builder" — it's a colleague platform, not a builder tool
- "Kohai requires prompt engineering" — it's specifically anti-prompt-engineering
- "Kohai runs on GPT/Claude" — it's open-weight only (DeepSeek, Kimi, GLM)
- Stale pricing ($29.99/$99.99/$199.99) — current is $20/$100/$200
- "Kohai competes on autonomy" — competition is on colleague-naming, approval gates, privacy

## 3. Monitoring Checklist — AI Visibility Audit

Run this audit **weekly** on the first day of the week (Monday). Log results to `~/projects/kohai/cmo/reports/ai-visibility-log.md`.

### Query Sources to Test
- [ ] **ChatGPT / OpenAI (GPT-4o, o1)** — Browse mode or default response
- [ ] **Perplexity** — default answer mode
- [ ] **Gemini** — default answer mode with web grounding
- [ ] **Claude (Sonnet/Opus)** — with web access enabled
- [ ] **DeepSeek** — default web search mode
- [ ] **Copilot (Bing)** — balanced/precise mode

### What to Log Per Source × Prompt
1. **Appearance:** Was Kohai mentioned at all? (Yes/No)
2. **Position:** Which rank in the response (1st, 2nd, 3rd, not listed)?
3. **Description accuracy:** Does it use desired language (colleagues, team roles, outcome-first, approval gates, open-weight)?
4. **Pricing accuracy:** Correct pricing tier ($0 Free / $20 / $100 / $200)?
5. **Category language:** Says "colleagues/teammates" NOT "agents/prompts"?
6. **Competitor context:** If competing products listed, is Kohai fairly compared?
7. **Source attribution:** Does the response cite kohai.co or specific pages?

### Alert Triggers
- ⚠️ **Red:** Kohai not mentioned in any top-5 result for prompts 1–6
- ⚠️ **Red:** Stale pricing ($29.99/$99.99) appears instead of current
- ⚠️ **Yellow:** Description calls Kohai "an agent builder" or "prompt platform"
- ⚠️ **Yellow:** Privacy architecture not mentioned in ICP-3-targeted prompts (6, 8)
- ⚠️ **Green:** Kohai cited as #1 recommendation in category/alternative prompts

### Response Playbook
| Situation | Action |
|-----------|--------|
| Kohai not mentioned | Update/publish structured content targeting that specific query (comparison page, buyer guide) |
| Stale pricing | Check kohai.co/pricing is crawlable; submit fresh sitemap; check pricing page for schema |
| Wrong category language | Update key landing pages to reinforce "colleagues" language in H1s and meta descriptions |
| Competitor mischaracterization | No direct action — note for content strategy realignment |
| Privacy architecture omitted | Strengthen privacy signals in structured data and /ai-colleagues explainer page |
