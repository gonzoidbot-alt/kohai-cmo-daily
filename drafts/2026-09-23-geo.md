## 3. Monitoring checklist (weekly, ~45 min)

**Setup (one-time, this week):**
- [ ] Create `cmo/geo-tracker.csv` with columns: date, engine, prompt_id, mentioned (y/n), accurate (y/partly/n), position_in_answer, cited_sources, notes/fix needed.
- [ ] Publish llms.txt + product schema + /ai-colleagues explainer (04 week-1 GEO must-fix) — these are what engines should start citing; until they're live, treat baseline mentions as the floor.
- [ ] Confirm kohai.co is UNgated (plain HTTP GET readable) — AI crawlers can't fill forms; sitemap entry for unlinked pages (06 Stage 2).

**Weekly run (human executes — no engine API in this loop):**
- [ ] Run all 13 prompts in ChatGPT, Perplexity, Gemini, Claude (same phrasing, fresh chat per prompt to avoid context contamination; note Perplexity should be asked with sources visible).
- [ ] Log each engine × prompt result in geo-tracker.csv (mentioned / accurate / position / cited sources).
- [ ] For every inaccurate description, record the exact URL the engine cited — that's the page to fix, not the engine.
- [ ] Check whether our target pages (comparison posts, /ai-colleagues explainer, pricing page) appear in cited sources for P1–P10.
- [ ] Search Reddit/G2 for new third-party mentions of Kohai (top-4 cited domains across AI engines are Reddit, YouTube, LinkedIn, Wikipedia per 06) — reply useful-first where appropriate.

**Weekly rollup (metrics into the CMO loop):**
- [ ] Mention rate: mentions ÷ (13 prompts × 4 engines) — target trend, not absolute (launch baseline expected near zero outside ChatGPT memory of stale data).
- [ ] Accuracy rate: accurate ÷ mentions — target ≥90%; anything below gets a same-week fix task.
- [ ] Category-phrase check: does "AI colleagues" increasingly appear in engine answers unprompted (P2, P5, P9)?
- [ ] Cited-source watchlist: which of OUR pages are engines citing; which competitor-comparison pages we don't yet have are they citing instead.
- [ ] Monthly (first Monday): full re-run of 06's 10 audit prompts in addition to this list; compare against baseline for the north-star "AI colleagues phrase association" metric.

**Escalation triggers:**
- Any engine hallucinating Kohai's pricing/model names → same-day fix task (schema + llms.txt + a stated-facts page the engine can quote).
- A competitor appearing in ≥50% of answers where we're absent → commission that comparison page (pillar 5).
- Kohai described as "agent builder" anywhere → highest-priority fix; that's the anti-position.
