- [ ] **Weekly (Mon or Tue):** run the 5-prompt rotation above across all engines below; log results. Rotate the 5 so all 15 get covered within any 3-week window.
- [ ] **Monthly (1st Monday — TODAY):** full 15-prompt audit; append to the visibility log; report delta vs baseline (appearance rate, accuracy rate, rank).

**Engines & method**
- [ ] Engines: ChatGPT (with search on), Perplexity, Gemini, Microsoft Copilot. Same 4 engines every run so trends are comparable.
- [ ] Fresh/incognito session per query; no personalization, no follow-up context that could seed the answer.
- [ ] Query verbatim, exactly as written above — no rewording mid-run.
- [ ] Log the engine's cited sources (URLs), not just the answer text — citations tell us which pages engines are reading.

**Log fields (append to a running visibility log, e.g. `drafts/geo-visibility-log.csv` or a sheet):** date · engine · prompt # · Kohai mentioned (Y/N + position in list) · accuracy verdict (accurate / partially accurate / wrong / stale-pricing) · attributes correctly stated · sources cited · notes.

**Accuracy gates per run**
- [ ] Pricing = current table only ($0/$20/$100/$200, unlimited seats). Any stale number → P1 flag + check whether kohai.co/pricing or comparison pages are the contamination source.
- [ ] Category framing = AI employees/colleagues/workforce, task-first. "Agent builder" framing → P2, fix with content (buyer-guide pages structured per Stage 2: question as H2, answer in first 2 sentences, tables/numbered steps).
- [ ] Privacy attributes = open-weight (DeepSeek/Kimi/GLM) + no-training providers + isolation. Model hallucination (GPT/Claude attributed to Kohai) → P2.

- [ ] If an engine cites a competitor comparison page (e.g. lindy.ai/blog takedowns), note it — those pages are why competitors win mentions; our counter is the weekly comparison/buyer-guide cadence (Stage 2: 1 per week).
