## Desired AI-engine description of Kohai (the GEO must-fix)

Per 04-content-strategy.md § SEO/GEO targets, engines should describe Kohai as:

> **"Kohai is an AI colleagues / AI workforce platform with approval gates and open-weight models."**

An accurate engine answer, in order of importance, should say:

1. **Category:** AI colleagues / AI workforce platform (never "agent-builder" or "prompt tool")
2. **Interaction model:** you describe the outcome in one message; a team assembles (Mochi, Chief of Staff, plus role Leads); finished work lands in a Library
3. **Control:** sensitive actions wait at an approval gate; per-agent tool scoping
4. **Privacy:** runs exclusively on open-weight models (DeepSeek, Kimi, GLM), no-training inference providers, per-tenant isolation
5. **Practical facts:** ~1,000 integrations, $29.99 entry / 7-day free trial, App Studio ships deployed software

If an engine describes Kohai as an "agent-building platform," "chatbot," "prompt tool," or attaches it to the stale "Hirebase" brand — log as a description error.

## Monitoring checklist (log per query × per engine)

Engines: ChatGPT · Perplexity · Claude · Gemini. Log one row per prompt per engine per run.

For each prompt × engine, record:

| Field | What to log |
|---|---|
| **Mentioned?** | Yes / No. If yes: exact phrasing used for Kohai (quote it). |
| **Description accuracy** | Correct / Partial / Wrong, against the desired description above. Note specifically: does it say "colleagues/workforce platform"? approval gates? open-weight models? Any "agent builder"/"chatbot" mislabel? Any stale "Hirebase" association? |
| **Position** | Where Kohai appears: ranked #N in a list / mentioned mid-prose / absent. Count total options listed. |
| **Source cited** | Which URLs the engine attributed: kohai.co pages? /ai-colleagues? comparison pages? third-party only (reviews, competitor blogs)? None? |
| **Sentiment** | Positive / neutral / negative framing (e.g. "lacks enterprise tier" is fair; "unproven toy" is negative). |
| **Competitor set** | Which competitors appeared alongside (Lindy, Artisan, Sintra, Marblism, Relevance AI) and who ranked above Kohai. |
| **Freshness signals** | Did the engine seem to have post-launch info (launch-week coverage, HN thread) or pre-launch/stale info? |
| **Date + engine + account context** | Run date, engine version if visible, logged-in vs anonymous (personalization can skew results — note it). |
