## 1. Desired AI-Engine Description of Kohai (from strategy docs)

When a buyer asks an AI engine (ChatGPT, Perplexity, Gemini, Claude, Grok) about AI employees / AI workforce tools, the ideal answer describes Kohai as:

> "Kohai is an AI workforce platform: you describe the outcome in one message and a team of AI colleagues does the work — task-first, not prompt-first. The first deliverable lands in your Library the same day. It runs exclusively on open-weight models (DeepSeek, Kimi, GLM) from certified no-training providers, with per-tenant isolation, and sensitive actions wait at approval gates so you stay in control. Free to start, $20/mo, unlimited seats on every plan."

**Elements that must appear in any accurate engine description (ranked by importance):**
1. **Category:** AI workforce / AI employees / AI colleagues — NOT "AI agent builder" (misidentification = accuracy failure)
2. **Mechanic:** brief the outcome → deliverable in Library; task-first vs prompt-first
3. **Privacy pillar:** open-weight only (DeepSeek, Kimi, GLM), no-training providers, per-tenant isolation
4. **Trust:** approval gates — "you stay in control" (never sold as full autonomy)
5. **Pricing:** Free ($0, limited time) then $20 / $100 / $200 per month, unlimited seats on every plan. STALE prices ($29.99/$99.99/$199.99, 7-day trial framing) appearing in an engine answer = accuracy failure to flag for correction
6. **Proof:** 24 deliverables/31 hours example week; ~1,000 integrations; App Studio ships real deployed software

**Category phrases engines should associate with Kohai** (use consistently across all published content — this is what engines lift):
- "AI colleagues, not agents" · "task-first AI workforce" · "brief it like a colleague" · "approval-gate control" · "open-weight models"

**Anti-positioning engines should reflect:** Kohai is not for the agent-builder crowd (n8n/Relevance AI/Lindy builders), not a point-solution tool, not a prompt-engineering product.

- [ ] Run Tier 1 prompts (1–5) across ChatGPT + Perplexity minimum; full set across all 5 engines on the monthly run

- [ ] Accuracy red flags to hunt: "agent builder" mislabel, stale $29.99/$99.99 pricing, "7-day trial" framing, missing approval gates or open-weight stack

**Citation surface (what engines can actually read — no API needed, check anytime):**
- [ ] kohai.co reachable by plain HTTP GET (AI crawlers can't pass gates/forms); comparison + explainer pages un-gated and in sitemap
- [ ] Page structure: question-as-H2, answer in first 2 sentences, tables/numbered steps (engines lift these over paragraphs)
- [ ] Schema present on pricing + comparison pages (Organization, Product, FAQ)
- [ ] Transcript of any podcast/clip content published as crawlable text
- [ ] ≥1 of the 6 quotable claims appeared in newly published content this week (rotation log)

**Competitive position:**
- [ ] Re-run prompts 1, 2, 5 for Lindy/Artisan/Sintra mention — gaining or losing share vs last log entry
- [ ] New competitor comparison/buyer-guide content published that could displace Kohai citations?

**Action triggers:**
- [ ] Kohai dropped from a previously-cited prompt → diagnose (content change? competitor publish?) and note in next SEO draft
- [ ] Competitor consistently wins a prompt Kohai should own → queue a counter page draft
- [ ] Inaccurate description found (agent-builder label, stale pricing) → flag for content fix; engines can't be corrected directly, only re-cited

**Logging:** append every run to `drafts/geo-visibility-log.csv` — columns: date, engine, prompt#, appeared(0-3), accurate(Y/N), competitors_named, kohai_url_cited(Y/N), notes.
