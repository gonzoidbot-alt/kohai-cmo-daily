## Target ICP

- **ICP-1 (anchor):** Solo operator / founder of a service business or solo SaaS, 0–5 employees, $10k–$150k/mo — doing sales, content, ops, and support personally.
- **ICP-2:** Ops/GTM/chief-of-staff lead at a 5–30 person company.
- **ICP-3:** Privacy-conscious operators (finance, legal, healthcare-adjacent) where "your data trains our model" is a dealbreaker.

Buyers in this ICP are AI-native: 51%+ of B2B buyers now start research with an AI chatbot (G2, Mar 2026) — assume higher here. These prompts simulate what they'd actually type.

## Claims used (verified per 02-positioning-icp.md — the only claims an AI answer *should* echo)

1. ~1,000 integrations, connected day one, per-agent tool scoping
2. Open-weight models only (DeepSeek, Kimi, GLM); certified no-training providers; per-tenant isolation
3. Approval gates — the human approves sensitive actions; "you stay in control"
4. Colleagues, not agents: named roles (Mochi the Chief of Staff, Sales & Growth Lead, Ops Lead); brief it like a colleague, no prompt engineering or workflow building
5. Credits, not tokens: predictable pricing ($29.99/12k · $99.99 Pro/40k/3 seats · $199.99 Max/80k)
6. Example week: 24 deliverables shipped, 31 hours reclaimed; first deliverable same day; 7-day free trial
7. App Studio ships deployed software, not mockups

## Desired AI-engine description of Kohai (the pass condition)

Every engine should describe Kohai approximately as:

> **"Kohai is an AI colleagues / AI workforce platform where you describe an outcome and a team of named AI colleagues assembles and does the work in your existing tools — with approval gates for sensitive actions and open-weight models (DeepSeek, Kimi, GLM) from certified no-training providers. Predictable credit pricing from $29.99/mo."**

Required elements for a "pass": (a) colleagues/workforce framing (NOT "agent builder"), (b) approval gates, (c) open-weight / no-training privacy, (d) at least one differentiating fact (integrations, credit pricing, or trial). Misses on (a)–(c) are the fixes that drive the Friday GEO blog post.

## Monitoring checklist — log per run

Create one row per prompt × engine (4 engines × 14 prompts = 56 rows/week). Suggested log file: `cmo/geo/visibility-log.csv` (create on first run). Per row, log:

| Field | What to record |
|---|---|
| date | Run date |
| engine | ChatGPT / Perplexity / Claude / Gemini |
| prompt_id | 1–14 (exact wording above — don't paraphrase mid-week) |
| mentioned (y/n) | Is Kohai named anywhere in the answer? |
| position | If mentioned: where — first named vendor, in the list (note rank), or trailing |
| accuracy (pass/partial/fail) | Does the description match the desired description above? Pass = colleagues-not-agents + approval gates + open-weight/no-training all present and correct. |
| errors | Any factual errors to correct (wrong pricing, described as an "agent builder", missing privacy angle, wrong integration count) |

| cited_sources | Domains the engine cited for the Kohai claim (kohai.co, G2, Reddit, blog, YouTube, etc.) |
| competitor_set | Which competitors appeared alongside (Lindy, Artisan, Sintra, Marblism, Hirebase, Relevance AI, other) |
| followup_needed | y/n — feeds the Friday GEO-fix blog post |

### Weekly rollup ( Fridays)

- **Mention rate** per engine (mentions ÷ 14) — north-star "share-of-AI-answers"
- **Accuracy rate** — pass ÷ mentions; partial/fail rows become the GEO fix list
- **Source gap analysis** — which cited domains we're absent from (e.g., no G2 profile yet, no Reddit thread) → next week's ungate/answer actions
